## How to Use This Repository

- Each experiment has a separate folder.
- `program.txt` contains the program or procedure performed for that experiment.
- The experiment-level `README.md` explains the objective, requirements, steps, and result.
- The `screenshots/` folder stores screenshots that document the process and result.

## Notes

Screenshots should show your own work. Add them to the relevant experiment's `screenshots/` folder and reference them in that experiment's README.
