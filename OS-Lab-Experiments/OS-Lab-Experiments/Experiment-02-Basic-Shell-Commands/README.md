# Experiment 02: Execution of Basic Shell Commands in Ubuntu Linux

## Aim
To execute and understand basic shell commands in Ubuntu Linux.

## Requirements
- Ubuntu Linux installed on a computer or virtual machine
- Access to the Ubuntu Terminal

## Commands Covered

| Command | Purpose |
|---|---|
| `pwd` | Display the current working directory |
| `ls` | List files and directories |
| `ls -l` | Show a detailed file listing |
| `cd` | Change the current directory |
| `mkdir` | Create a directory |
| `rmdir` | Remove an empty directory |
| `touch` | Create an empty file or update its timestamp |
| `cat` | Display or combine file contents |
| `cp` | Copy files or directories |
| `mv` | Move or rename files |
| `rm` | Remove files |
| `clear` | Clear the terminal display |
| `whoami` | Display the current username |
| `date` | Display the system date and time |
| `cal` | Display a calendar, if the command is installed |
| `uname -a` | Display system/kernel information |
| `df -h` | Display disk-space usage in readable units |
| `free -h` | Display memory usage in readable units |
| `history` | Show commands entered in the current shell history |
| `man` | Open a command's manual page, when available |
| `echo` | Print text or variable values |
| `wc` | Count lines, words, and bytes/characters |
| `grep` | Search text for a pattern |

## Procedure
1. Start the Ubuntu virtual machine.
2. Log in and open Terminal.
3. Enter each command shown in `program.txt`.
4. Observe the output and understand what the command does.
5. Capture screenshots of selected commands and their outputs.
6. Save your screenshots in this experiment's `screenshots/` directory.

## Safety Notes
- Check the current directory with `pwd` before deleting or moving files.
- Use `rm` carefully; deleted files may not be recoverable from the terminal.
- Do not run commands with `sudo` unless you understand why administrator privileges are needed.
- Output may differ depending on Ubuntu version, installed packages, permissions, and system configuration.
